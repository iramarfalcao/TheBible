Uma API aberta da Bíblia Sagrada e da Harpa Cristã.

## O que é

Repositório criado em 2021 para uma API aberta com o texto da Bíblia Sagrada e dos hinos da Harpa Cristã. Hoje contém apenas este README, a licença MIT e o `.gitignore`. Não há código, dados nem documentação além disso.

## O que faz

Nada ainda. A intenção descrita é oferecer, por uma API aberta, o acesso ao texto bíblico e aos hinos da Harpa Cristã.

## Funcionalidades

Nenhuma implementada no repositório.

## Como rodar

Não se aplica: não há código para executar.

## O que falta

Tudo. Não existe roadmap, backlog nem STATUS mapeando o que deveria ser feito. Antes de começar, vale decidir a fonte e a licença dos textos (traduções da Bíblia e a Harpa Cristã têm situações de direitos diferentes), a stack e o formato da API.
